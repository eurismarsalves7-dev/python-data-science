# Projeto 01 — Análise Preditiva de Evasão de Clientes com Python

Projeto acadêmico desenvolvido durante a formação em Ciência de Dados.

## Objetivo
Desenvolver um modelo preditivo para identificar clientes com maior probabilidade de cancelar serviços de uma empresa de telecomunicações.

## Tecnologias
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Metodologia
1. Análise exploratória dos dados.
2. Tratamento de valores ausentes.
3. Encoding de variáveis categóricas e normalização.
4. Divisão treino/teste 80/20 com estratificação.
5. Treinamento de Regressão Logística, Random Forest e Gradient Boosting.
6. Avaliação por Accuracy, Precision, Recall e F1-Score.
7. Curva ROC e otimização com GridSearchCV.
8. Análise de importância das variáveis.

## Resultados documentados
O Gradient Boosting foi descrito no projeto como o modelo de melhor desempenho, com F1-Score de 0,82 e AUC de 0,87.
